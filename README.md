# 1024节 · 我画 AI 猜

面向小学生与亲子家庭的绘画小游戏：玩家在平板或电脑上绘画，AI 实时猜测，工作人员根据结算发放活动标记。

**在线试玩：[双物体版](https://hcypkumain.github.io/I-Draw-AI-Guess-PKUCS-1024/)** · **[单物体高难度版](https://hcypkumain.github.io/I-Draw-AI-Guess-PKUCS-1024/hard/)**

两个版本并行部署，便于现场对比：双物体版每题画两个东西、两个都要被认出；单物体版每题画一个，但要求 AI 连续两次稳定认出。配置与依据分别见各自的《难度调整说明》（单物体版在 `single-object-hard` 分支）。

## 玩法

- 每局随机 2 题，每题最多 3 秒准备，落笔立即开始 20 秒绘画；未动笔也会在准备结束后自动开始。猜中或超时后自动换题；整局通常约 30–60 秒，也可提前完成。
- 简单档：每题两个东西都要画出，2 题过 1 题获得 1 个标记。
- 困难档：每题两个东西都要画出，2 题都要过获得 2 个标记；未达标获得 0 个标记。
- 自由练习不计时、不发标记。支持鼠标、手指和触控笔。
- 两档共用同一题库，每题都给两个东西，题面形如“救护车和苹果”，两个都要分开画出并被 AI 认出才算这题过。**唯一的区别是结算**：简单档 2 题过 1 题，困难档 2 题都要过。
- 高难度配置：每个物体有独立的识别门槛，只有画得极为接近才算认出。重放通过率：单题约 10.6%；简单档一局拿标记约 20%，困难档两题全过约 1.1%。
- 正式题库 211 个物体，两档共用，每题抽 2 个，一轮可组成 105 道题；另有 134 个暂停，可自由练习识别。这 211 个是把全部 345 类逐个放到双物体画布上实测筛出的，排除了模型在两个物体同时存在时认不出的类别。两个东西要分开画在画布两边，AI 分区识别，并需先完成 8 笔线条。模型仍识别全部 345 类，仍需儿童现场校准。完整名单见[类别判定说明](类别判定说明.md)。
- 正式挑战只显示 AI 的首选猜测，不列出备选类别；自由练习仍显示备选。
- 每档独立洗牌，一轮抽完才重复；换轮也避开最近 4 道已显示的题目，避免相邻两局重复。抽题进度保存在当前浏览器，刷新后继续；不同设备分别记录。自由练习不消耗题库，提前退出不跳过尚未显示的第二题。
- 保留“树／椰子树”等上下位类别的明确兼容判题规则；兼容答案同样需要达到该题门槛。

## 本地使用

用现代浏览器直接打开 `index.html`，等待“AI 已就绪”。网页内嵌运行库和模型，无需 API Key，画作在浏览器内识别，不上传。

平板与笔记本在同一 Wi-Fi 或热点时，可在本目录运行：

```powershell
python serve.py --lan
```

然后在平板浏览器输入终端显示的 `Tablet (same Wi-Fi)` 地址。使用在线试玩链接时，无需启动电脑上的服务器。

## 调整题库与验证

`index.html` 的 `embeddedQuestions` 保留全部模型类别元数据。`level` 为 `easy` 或 `hard`；`enabled: false` 会暂停正式抽题，须填写 `reviewReason`。修改启用列表或档位后，旧抽题进度会自动失效并按新题库重新洗牌；模型类别和兼容答案不受影响。

判分使用 `embeddedAnswerRules` 的 `pairConfidence`：题库内每个物体一个门槛，两档共用。值越高越难，`minimumConfidence` 是全局下限。要整体放宽或收紧，按比例调整这张表即可，无需改动代码或模型。`promptConfidence` 是单物体模式留下的旧表，当前不参与判分。

`embeddedQuestions` 控制题目结构：`pairObjects` 是每题给几个物体，`objectsNeeded` 是各档需要认出几个（当前两档都是 2），`pairMinimumStrokes` 是线条门槛，`sharedPool` 标记两档共用题库。把 `pairObjects` 设为 1 即可退回单物体模式。

注意：题库里的 211 个物体是逐个在双物体画布上实测筛出的。直接启用其他类别会让那些题目几乎无法通过——模型在两个物体同时存在时对笔画少的类别（勺子、三角形、月亮等）给不出正确的首选预测，调门槛无法解决。扩充题库应按同一流程复测候选，并同步校准 `pairConfidence`。

本轮调整依据与恢复条件见 [难度调整说明](难度调整说明.md)。安装 Node.js 后，运行 `node --test tests/game.test.cjs` 检查题库、去重、计时和结算，无需安装 npm 依赖。
