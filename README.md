# 1024节 · 我画 AI 猜

面向小学生与亲子家庭的绘画小游戏：玩家在平板或电脑上绘画，AI 实时猜测，工作人员根据结算发放活动标记。

**[点击在线试玩](https://hcypkumain.github.io/I-Draw-AI-Guess-PKUCS-1024/)**

## 玩法

- 每局随机 2 题，每题最多 3 秒准备，落笔立即开始 20 秒绘画；未动笔也会在准备结束后自动开始。猜中或超时后自动换题；整局通常约 30–60 秒，也可提前完成。
- 简单档：2 题猜中 1 题获得 1 个标记。
- 困难档：2 题全部猜中获得 2 个标记；未达标获得 0 个标记。
- 自由练习不计时、不发标记。支持鼠标、手指和触控笔。
- 两档共用同一题库，每题画一个东西，落笔即开始识别。**唯一的区别是结算**：简单档 2 题猜中 1 题，困难档 2 题都要猜中。
- 高难度配置：通过一题要求置信度达到该题门槛（每题单独校准，中位数约 94.5%），**并且连续两次检查都给出同一个合格答案**。网页每 0.5 秒看一次，所以画到一半偶然蒙对不算。
- 按画得较好的公开画作衡量，单题通过率约 9%，简单档一局拿标记约 17%，困难档两题全中约 0.8%。
- 正式题库 337 个物体，两档共用；另有 8 个暂停（在连续命中判定下命中率不足 10%），仍可自由练习识别。模型仍识别全部 345 类，仍需儿童现场校准。完整名单见[类别判定说明](类别判定说明.md)。
- 正式挑战只显示 AI 的首选猜测，不列出备选类别；自由练习仍显示备选。
- 每档独立洗牌，一轮抽完才重复；换轮也避开最近 4 道已显示的题目，避免相邻两局重复。抽题进度保存在当前浏览器，刷新后继续；不同设备分别记录。自由练习不消耗题库，提前退出不跳过尚未显示的第二题。
- 保留“树／椰子树”等上下位类别的明确兼容判题规则；兼容答案同样需要达到该题门槛。

## 本地使用

用现代浏览器直接打开 `index.html`，等待“AI 已就绪”。网页内嵌运行库和模型，无需 API Key，画作在浏览器内识别，不上传。

平板与笔记本在同一 Wi-Fi 或热点时，可在本目录运行：

```powershell
python serve.py --lan
```

然后在平板浏览器输入终端显示的 `Tablet (same Wi-Fi)` 地址。使用在线试玩链接时，无需启动电脑上的服务器。

## 调整题库与验证

`index.html` 的 `embeddedQuestions` 保留全部模型类别元数据。`level` 为 `easy` 或 `hard`；`enabled: false` 会暂停正式抽题，须填写 `reviewReason`。修改启用列表或档位后，旧抽题进度会自动失效并按新题库重新洗牌；模型类别和兼容答案不受影响。

判分由 `embeddedAnswerRules` 的三项控制：

- `promptConfidence`：题库内每道题一个置信度门槛，两档共用，值越高越难。
- `requiredStreak`：需要连续多少次检查给出同一个合格答案（当前 2）。这是本分支难度的主要来源，调到 3 需要重新校准门槛，否则大量题目会变成无法通过。
- `requiredMargin`：要求首选比次选高出的差距（当前 0，未启用）。

`embeddedQuestions` 控制题目结构：`pairObjects` 是每题给几个物体（当前 1），`singleMinimumStrokes` 是线条门槛（当前 0，即随画随猜）。

注意：门槛是按“每题画得最好的三分之一样本通过率落在 10%”校准的，而不是按全体样本——全体样本笔画偏少，按它校准会让认真画的玩家轻松通过。被暂停的 8 个类别在连续命中判定下命中率不足 10%，调门槛无法解决。

本轮调整依据与恢复条件见 [难度调整说明](难度调整说明.md)。安装 Node.js 后，运行 `node --test tests/game.test.cjs` 检查题库、去重、计时和结算，无需安装 npm 依赖。
